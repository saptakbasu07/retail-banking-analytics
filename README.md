
# 🏦 Retail Banking Analytics

## Overview

A banking analytics project built using SQL, Power BI, and Excel to analyze customer behavior, deposits, account activity, loan performance, and risk indicators.

## Tech Stack

- SQL (PostgreSQL)
- Power BI
- Microsoft Excel


## Key Areas of Analysis

### Customer Analytics
- Customer Segmentation
- High-Value Customer Identification
- Customer Tenure Analysis

### Deposit Analytics
- Average Balance Analysis
- Dormant Account Analysis
- Account Type Performance

### Loan & Risk Analytics
- Loan Default Analysis
- Risk Segmentation
- Income vs Loan Performance

### Digital Banking Analytics
- Channel Usage Trends
- Month-on-Month Growth Analysis

### Customer Service Analytics
- Resolution Time Analysis
- Customer Satisfaction Analysis


## Dashboard Pages

### Executive Summary
